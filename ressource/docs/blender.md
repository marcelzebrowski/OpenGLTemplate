## Shortcuts

|Befehl|Beschreibung|
|------|------------|
|Ctrl-n|Aktuelle Scene berenigen, neuladen usw.|
|Ctrl-s|Das aktuelle File speichern|
|Ctrl-Alt-s|Das aktuelle File als speichern|
|Ctrl-q|Quit Blender|
|F12 / fn2 + = |Rendern des Bildes |
|F11 / fn2 - = |Anzeigen des Renderer | 
|Ctrl + Alt + Space|Toggle Fullscreen|
|t|Toggle Toolbar|
|F9 / fn2 + 9|Letzte Operation justieren|
|n|Toggle Seitenleiste|
|q|Favorieten|
|w|will cycle between Select Box, Select Circle |
|F3 / fn2 + 3| Search for Operators|
|Ctrl + z| Undo|
|Ctrl + Shift + z| Undo|
|F9 / fn2 + 9| Letzte Operation justieren|
|Shift + r| repeat last|
|w|select box|
|Ctrl+i|Invert selection|
|g pressed|Objekt bewegen, aber gedrückt halten|
|r pressed|Objekt rotieren, aber gedrückt halten|
|s pressed|Objekt skalieren, aber gedrückt halten|
|Shift + a|Add|
|g pressed + z pressed|Objekt bewegen and der z Achse, aber gedrückt halten|\
|object mode| tab|
|object mode 1 2 oder 3| switch select mode|
|object mode e| extrude |
|object mode i| inset |
|object mode strg r| loop cut|
